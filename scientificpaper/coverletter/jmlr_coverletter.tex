Dear Editors:

We are writing to submit our manuscript ``torchtsetlin: Fast, Interpretable Tsetlin Machines for the
PyTorch Ecosystem'' to the \emph{Journal of Machine Learning Research}, for the
\textbf{Machine Learning Open Source Software (MLOSS)} track.

Our manuscript describes \texttt{torchtsetlin}, an open-source library that implements the
Tsetlin machine family (vanilla, weighted, coalesced, regression, convolutional over sequences,
images and volumes, and dense segmentation) as ordinary PyTorch modules. Tsetlin machines learn
human-readable propositional rules without gradients, but their software has so far consisted
of C and CUDA kernels that sit outside the deep-learning ecosystem. \texttt{torchtsetlin} stores
the automata as tensors, so models move between devices, serialise and consume data loaders like
any other PyTorch model, and it introduces a batched feedback algorithm that turns per-example
automaton updates into matrix products and binomial draws. This makes Tsetlin machines
practical on GPUs (\red{up to $X\times$} faster than the same code on a multi-core CPU) and
easy to extend in Python. The library is documented, tested on CPU and GPU, continuously
integrated, and released on PyPI.
