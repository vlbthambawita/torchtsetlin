# CIFAR-10: normal Tsetlin machines vs transformer-concept TMs

Generated by `code/cifar_report.py` from `results/cifar/*.json`; do not edit by hand. Protocol:

## Setup

- Data: CIFAR-10, thermometer Booleanization with 4 thresholds per channel (12 × 32 × 32 bits, the
  `experiments/convtm` cache), the convtm stratified 45,000 / 5,000 train/validation split, the official
  10,000-image test set read once per final run.
- Every arm: 2,000 clauses in total, T = 80, soft literal budget 32, batch 32, 30 epochs, best
  validation epoch kept. Class-wise clauses (200 per class), except the two graph arms, which are
  coalesced (2,000 shared clauses with per-class weights) because that is the graph TM's output layer.
- Specificity s searched on validation with seed 0 (s ∈ {2, 10, 40}; graph arms {2, 10}); finals with
  seeds 1–3 at the chosen s. The Q/K/V arm has one final seed (D17, user decision: it is ~6× slower).

| arm | model |
|---|---|
| Normal TM (flat) (`flat`) | `TsetlinMachine` on all 12,288 bits |
| Convolutional TM (`ctm`) | `ConvTsetlinMachine`, 4×4 patches, stride 1, position bits (841 patches) |
| Patch TM, no attention (`pair_self`) | 64 non-overlapping 4×4 patch tokens, each paired only with itself |
| Pair attention, neighbours (`pair_local`) | pair clauses Q(token i) ∧ K(token j) ∧ R(dy, dx) ∧ A(i), |dy|, |dx| ≤ 1 (576 pairs) |
| Pair attention, all pairs (`pair`) | the same over all 64 × 64 = 4,096 ordered pairs |
| Graph TM, depth 1 (no messages) (`qkv_d1`) | `GraphTsetlinMachine` on the 64 patch nodes, coalesced, no message passing |
| Q/K/V attention (graph TM, depth 2) (`qkv`) | values = layer-1 clause matches of sender j, hashed messages bound to 16 direction types, OR inbox, queries on receiver i |

| comparison | difference of means (pp) |
|---|---|
| attention TM vs the normal flat TM | +0.60 |
| attention vs the same tokens without attention (the attention effect itself) | -0.05 |
| neighbour attention vs no attention | +0.67 |
| global vs neighbour attention | -0.71 |
| the convolutional TM vs the attention TM | +5.44 |
| Q/K/V message passing vs the same graph TM without it (seed 1 only for qkv) | -3.14 |
| Q/K/V attention vs pair attention | -9.22 |

**Why Q/K/V message passing does not help (D-H2a, `THEORY_HTM.md` H2.2).** In the trained Q/K/V model a mean
4.0 % of the 2,000 layer-1 clause parts match at a patch (empty parts, which match everywhere: 1),
so each receiving patch's 1,024-bit inbox is 98.4 % full on average
(minimum 61.5 %; H2.2 predicts 100.0 %). Saturation sets in at
f ≈ 1.9 %. A nearly all-ones inbox carries almost no information about the senders;
yet 64.2 % of the included literals are inbox literals. On a bit that is almost always 1, a
positive literal is a near-free condition and a negated one fires only on the rare empty slot, so the
learner spends literals on bits that carry little signal: the independence approximation of H2.2
slightly overstates the density (it ignores correlated senders), but the saturation is real.

## Reading

- **The convolutional TM is the best TM here, and attention does not close the gap.** All
  pair-attention arms sit about where the patch TM without attention sits, a little above the
  flat TM and well below the convolutional TM. The likely reason for the convolutional TM's lead
  is not attention but **overlap**: it evaluates every clause on all 841 overlapping 4×4 patches
  (stride 1), while every token-based arm sees only the 64 non-overlapping patches. A pair
  clause can relate two patches, but it cannot see the 3/4 of the 4×4 windows that straddle
  token borders.
- **Attention itself contributes nothing measurable on CIFAR-10 in this configuration.** Global
  pair attention ties its no-attention ablation, and neighbour attention is less than one point
  above it. In the synthetic tasks the pair clause won exactly where the label is a relation
  between two tokens at content-dependent positions (co-occurrence T5, order T1). With these
  settings, CIFAR-10 class evidence does not seem to come from such pairwise relations of
  4×4 patches. Global pairs are also 64× more columns to search per clause (the dilution of
  `THEORY.md` C2): s = 2 won the search for every arm, the opposite of what the synthetic
  attention tasks needed.
- **The explicit Q/K/V arm is the weakest.** Two causes, both measured. (i) The graph TM uses
  coalesced clauses with per-class weights; its depth-1 control already loses to the class-wise
  arms, so part of the loss is the output layer, not attention. (ii) Message passing on top of it
  loses again, and D-H2a shows why: the OR inbox is almost always full, so the received
  "values" carry almost no information about the senders (`THEORY_HTM.md` H2.1–H2.2). The
  per-class table shows the effect: the Q/K/V model collapses on several classes. This is the
  failure that the HTM plan's sparse-value arm (H2, E-H2b) targets.
- **Cost.** Global pair attention is about 40× slower per run than the convolutional TM for no
  gain; neighbour attention costs little and gives at most a small gain over no attention.

## Limits

- One clause budget (2,000), one T, one Booleanization, 30 epochs; the convtm programme reached
  higher accuracy with far larger CTMs, so the absolute numbers are those of a small budget.
- s searched with one seed; three final seeds per arm, one for Q/K/V (D17).
- Tokens are non-overlapping 4×4 patches. Overlapping tokens (stride 2) would test the overlap
  explanation directly, at 4× the tokens and 16× the pairs.
