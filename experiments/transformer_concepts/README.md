# Positional encoding and key–query–value attention for Tsetlin machines

Brief: `torchtsetlin_plans/experiments/transformer_concepts/idea_v2.md` (from `torchtsetlin_plans/experiments/transformer_concepts/idea.md`).

- [THEORY.md](THEORY.md): how positional codes and attention look in clause logic, with proofs.
  The core result is that a TM attention head is a **clause over pairs of tokens**
  $Q(x_i) \land K(x_j) \land R(j-i)$ OR-ed over pairs. It runs as a convolutional TM over pair
  columns and learns with the unchanged conv feedback. Relative position must be a pair feature,
  because no absolute code can provide it cheaply (Theorem A7).
- `torchtsetlin_plans/experiments/transformer_concepts/PLAN.md`: tasks T1–T6, arms, preregistered decision rules, kill criteria, phases, cost.
- [THEORY_HTM.md](THEORY_HTM.md) and `torchtsetlin_plans/experiments/transformer_concepts/PLAN_HTM.md`: Hierarchical Temporal Memory ideas
  (tolerant clauses H1, sparse value codes H2, recurrent state with local targets H3); run 2026-11-09,
  results in [REPORT_HTM.md](REPORT_HTM.md) (generated by `code/htm/report.py`).
- [REPORT_CIFAR10.md](REPORT_CIFAR10.md): CIFAR-10 arms (flat, ctm, pair variants, Q/K/V graph TM).
- [THEORY_REVIEW.md](THEORY_REVIEW.md): proposition-by-proposition check of the theory; what was
  wrong and how it was corrected.
- [DECISIONS.md](DECISIONS.md), [LIBRARY_GAPS.md](LIBRARY_GAPS.md).
