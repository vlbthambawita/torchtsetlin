# fmnist_bitplanes: bit-plane Booleanization on Fashion-MNIST, flat vs 2D conv vs 3D conv TM

**Question.** A grey pixel is 8 bits, `v = B0 + 2·B1 + … + 128·B7`. Is this bit-plane encoding a
useful Booleanization for a Tsetlin machine, compared with the paper's adaptive Gaussian
threshold (B8) and with thermometer planes at the same bit budget? And does a 3D convolution over
the plane axis help? Request: `source_documents/TODO/quesry_FMNIST_testing_plane_binary.md`.
Plan (decisions, hypotheses, phases): `torchtsetlin_plans/plans/fmnist-bitplanes.md`.

`REPORT*.md` are generated by `code/report.py` from `results/`; do not hand-edit.

## Cells (plan §2.3, D1 as decided by the user on 2026-11-13)

**Staged (plan v3):** stage A runs only the conv3 cells (bit8, gray8). Stage B, the flat / conv2
comparison, runs only if the user decides so after checking stage A (`queue_runner.py --stage B`).
**kd = 8 (plan v4):** the conv3 window covers all 8 planes (one depth position), which makes it the
same model as a 2D conv over 8 bit-plane channels.

| | AGT (B8, 1 plane) | THERM8 | BIT8 | GRAY8 |
|---|---|---|---|---|
| flat (B4 base) | **core** | control | control | control |
| conv2 (B8 base, planes as channels) | **core** | control | control | control |
| conv3 (B8 base, planes along depth, window `(kd, 10, 10)`) | — | — (user: skip) | **core** | control |

C ∈ {2 000, 8 000} clauses per class, T scaled with C, B = 32, early stopping as
`mnist_batch_clauses` v4 (validation 50 000 / 10 000 stratified seed 0; patience 25, min_delta 0, min 30,
max 500 epochs, 24 h). Statistic: test accuracy at the best-validation epoch. Every epoch records
`plane_usage`, the share of included literals on each plane.

## Layout

| Path | What |
|---|---|
| `code/common.py` | paths, cells, base configs, encodings (`encode`), data + split, records |
| `code/train.py` | one run (or `--calibrate N` for pricing) |
| `code/tracking.py` | W&B mirror, run id `fm-<arm>-<tag>`, group = arm |
| `code/queue_runner.py` | works through an arm on the 3080; claims in `.cache/claims/` |
| `code/check_encodings.py` | exactness of every encoding + the plane-layout bookkeeping |
| `code/report.py` | `REPORT_<arm>.md`, `REPORT.md`, `results/summary.json`; `--arm pilot --choose` writes the pilot choice |
| `code/smoke.sh` | the smoke test |
| `results/<arm>/<tag>.json` | one record per run; tag = `<arch>_<enc>_c<C>_spec<s>[_kd<k>]_seed<seed>` |

python code/report.py --arm pilot --choose
