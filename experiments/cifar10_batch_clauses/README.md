# cifar10_batch_clauses: batch size × clauses per class on CIFAR-10 (flat, 2D conv, 3D conv TM)

**Question.** How do batch size (1–1024) and clauses per class (1k–32k) affect final CIFAR-10 accuracy
and training time of flat, 2D convolutional and 3D convolutional Tsetlin machines? The CIFAR-10
companion of `mnist_batch_clauses`. Plan (questions, hypotheses, decisions D0–D15, cost):
`plans/cifar10-batch-clauses.md`. Runs on a server with four 32 GB V100s; W&B mirror:
https://forge.coreweave.com/wandb/simulamet_mlc/TM_CIFAR

## Quick start (on the V100 server)

```bash
git clone https://github.com/vlbthambawita/torchtsetlin.git
cd torchtsetlin/experiments/cifar10_batch_clauses
wandb login --host https://api.forge.coreweave.com   # once
./setup.sh          # Python env, CIFAR-10, GPU check, smoke test (~20 min)
./run_gpu0.sh       # one runner per V100; they share one job list
./run_gpu1.sh
./run_gpu2.sh
./run_gpu3.sh
./status.sh         # progress
```

**One reserved GPU per tmux session** (each session sees one GPU): run `./setup.sh` once (any
session), then `./run_gpu0.sh` in the first session, `./run_gpu1.sh` in the second, and so on. A
runner uses whichever single GPU its session sees; the number only names it (`logs/gpuK.log`).
All four must run in the same folder (they share the job list through `.cache/claims/`).

Each `run_gpuK.sh` starts a background runner for GPU K (log `logs/gpuK.log`, one log per run in
`logs/runs/`). The runners work through pricing → flat pilot → sanity cell → grid (longest first) →
controls, and exit when nothing is left. Re-running a script resumes: finished runs are skipped,
interrupted runs continue from their checkpoint. `./stop.sh` stops after the current runs,
`./stop.sh --now` immediately (resumable); remove `STOP` to continue. Results come back to mimir with
`rsync -a <server>:<path>/results/ results/` (or a commit); then `python code/report.py`.
The best-epoch models stay in `models/` on the server (git-ignored); copy them with
`rsync -a <server>:<path>/models/ models/` when needed. Interrupted runs resume from
`.cache/ckpt/` (every 5 epochs, deleted when the run ends).

Knobs: `CBC_VENV=none` (use the active Python instead of `./.venv`), `TORCH_INDEX=<wheel
index>` (default cu126, which has V100 kernels), `CBC_WANDB=0` (no W&B), `CBC_DEVICE=cpu` (harness
test without a GPU).

## Rules

| # | Rule |
|---|---|
| R1 | `src/torchtsetlin/**` is **read-only** here. Library defects go to `LIBRARY_GAPS.md`. |
| R2 | Every number comes from a `results/<arm>/<tag>.json` record carrying `argv`, `seed`, `git_sha`, `env`. W&B is a mirror. `REPORT.md` is generated by `code/report.py`; do not hand-edit. |
| R3 | Nothing is tuned per cell; the only selection is the flat pilot (D3), on validation. |
| R4 | Early stopping watches the 5 000-image validation split, never the test set. |
| R5 | Seed 0 only until the user approves more seeds (D13). |

## Grid

| | conv | conv3 | flat |
|---|---|---|---|
| Input | colour thermometer, 8 levels/channel (24 × 32 × 32) | 8 bit planes/channel (3 × 8 × 32 × 32) | colour thermometer, 3 levels/channel (9 216 bits) |
| Model | ConvTM 3 × 3, position encoding | Conv3dTM (8, 3, 3), position encoding | flat TM |
| T at 2k, s | 3 000, 5 (Toolbox 3 × 3 thermometers) | 3 000, 5 | from the pilot |
| C/class | 1k–32k | 1k–32k | 1k–8k |

All: B ∈ {1, 16, 32, 64, 128, 256, 512, 1024}, T ∝ C, `max_included_literals = 32` (soft), seed 0;
validation 45 000 / 5 000; patience 25 (any new best counts), min 30, max 500 epochs, 24 h per run.
Statistic: test accuracy at the best-validation epoch.

## Layout

| Path | What |
|---|---|
| `setup.sh`, `env.sh` | one-time setup; shared environment (venv, W&B host) |
| `run_gpu0.sh` … `run_gpu3.sh`, `run_gpu.sh` | one runner per GPU slot |
| `gpu_device.sh` | slot K → `CUDA_VISIBLE_DEVICES` (the K-th entry of an existing list, e.g. under SLURM, else K) |
| `status.sh`, `stop.sh` | progress; graceful / immediate stop |
| `code/common.py` | paths, grid, base configs, encodings, data + split, records |
| `code/data.py` | CIFAR-10 download + checks → `.cache/data/cifar10_uint8.npz` |
| `code/train.py` | one run (or `--calibrate N` for pricing) |
| `code/queue_runner.py` | the shared job list, claims in `.cache/claims/`, pilot choice, sanity gate |
| `code/tracking.py` | W&B mirror, id `cbc-<arm>-<tag>`, group = arm |
| `code/resume_check.py` | smoke: interrupted + resumed run = uninterrupted run |
| `code/report.py` | `REPORT.md`, `results/summary.json`; `--status` for progress |
| `models/<arm>/<tag>.pt` | **not in git**: the model at the best-validation epoch of every run (state_dict + hp + epoch + val/test accuracy), ~35 GB in total |
| `results/<arm>/<tag>.json` | one record per run; tag = `<model>_c<C>_b<B>_T<scaled|fixed>[_seq][_Tref<T>_spec<s>]_s0` |
