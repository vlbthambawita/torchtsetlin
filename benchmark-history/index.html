    Adding a version¶

    pip install -e .                    # the version to measure
./benchmarks/run_benchmarks.sh      # writes benchmarks/results/versions/<version>/

    Each run writes to the folder of the installed library version, so the results of older versions are never overwritten. The driver then regenerates CPU vs GPU for the newest version and this page for all of them; python benchmarks/plot_history.py rebuilds this page alone.
